Case study

Agile Portfolio Development on Linux

Role: Frontend Developer | Stack: Ubuntu OS, GitKraken, HTML5

Project overview

This project came together under a tight deadline at the start of the academic year. The goal was to transition to a Linux-based development environment and launch a complete multi-page portfolio quickly, without sacrificing structure or content quality.

The Linux workflow

Instead of relying on a familiar Windows setup, I built the work entirely in Ubuntu. I configured the terminal for a comfortable workflow, adapted the keyboard layout for efficient input, and connected GitKraken to GitHub for a clear visual version-control process. That forced me to adapt quickly and work in a cleaner, more disciplined environment from the start.

Focus on content & semantics

Because the timeline was short and accessibility is central to my values, I intentionally avoided heavy frameworks. The project is built around semantic HTML5 and strong page structure so content remains clear for screen readers and easy to extend later. This gave me a stable foundation for the visual styling phase.

Project snapshot

  • Built in a Linux-first developer setup
  • Managed with Git and GitHub
  • Structured around accessibility and semantics
  • Designed for quick iteration and clean handoff
