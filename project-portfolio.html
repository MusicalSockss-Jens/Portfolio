Case Study: Agile Portfolio Development on Linux

Role: Frontend Developer | Stack: Ubuntu OS, GitKraken, HTML5

Project Overview

Dit project is ontstaan uit een strakke deadline aan de start van het academiejaar. Het doel was om in minder dan een week tijd een volledige transitie te maken naar een Linux-ontwikkelomgeving én tegelijkertijd een functioneel, multipage portfolio op te leveren.

The Linux Workflow

In plaats van te vertrouwen op Windows, heb ik dit project volledig opgebouwd binnen Ubuntu Linux. Ik heb de terminal geconfigureerd met de juiste keyboard-mapping (English US intl. met dead keys) en GitKraken gekoppeld aan GitHub voor een feilloos, visueel versiebeheer. Dit dwong me om direct vanaf dag één agile te schakelen in een nieuw OS.

Focus on Content & Semantics

Omdat de tijd beperkt was en webtoegankelijkheid (a11y) mijn kernwaarde is, heb ik er bewust voor gekozen om zware frameworks links te laten liggen. De focus lag volledig op pure, semantische HTML5. De structuur is zo opgebouwd dat screenreaders de content logisch kunnen verwerken, wat de perfecte fundering vormt voor de stylingfase die hierna volgt.
